조과일지 계정 · 데이터 삭제 방법

앱 이름: 조과일지 (패키지 kr.jogwailji.app)

앱에서 바로 삭제하기

  1. 조과일지 앱을 열어요.
  2. ⚙ 개인 설정으로 가요.
  3. 맨 아래 🚪 계정 삭제 (회원 탈퇴)를 누르고 안내대로 진행해요.
  4. 본인 확인을 위해 구글 로그인을 한 번 더 하면 바로 지워져요.

지워지는 것

  • 그룹에 올린 내 출조 기록 (이동 경로 · 사진 포함), 그룹 채팅의 내 글, 그룹 회원 정보
  • 전체 게시판에 올린 내 글 (사진 · 경로 포함), 전체 채팅의 내 글
  • 서버 백업, 닉네임, 내 계정 정보, 구글 로그인 계정

남는 것

  • 이용자 폰에 저장된 기록 · 사진 · 설정은 폰에 그대로 남아요. 필요 없으면 앱을 지우세요.
  • 1:1 문의 내용은 운영자가 확인 후 지워요.
  • 이용 정지 · 신고 처리 기록은 재가입 악용을 막기 위해 필요한 기간 동안 보관할 수 있어요.

앱을 쓸 수 없을 때 삭제 요청하기

앱을 이미 지웠거나 로그인할 수 없으면, Google Play 스토어 조과일지 페이지의 '개발자 연락처' 이메일로 가입한 구글 이메일 주소와 함께 "계정 삭제 요청"을 보내 주세요. 확인 후 7일 안에 지우고 알려 드려요.
