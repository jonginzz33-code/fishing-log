# 조과기록 (fishing-log)

블루투스 리모컨 버튼 2개로 낚시 조과를 기록하는 안드로이드 앱.

## 1단계 기능
- 출조 시작/종료
- 리모컨 버튼 등록 (1번, 2번)
- 화면이 꺼져 있어도 리모컨으로 카운트 (재생/다음 곡 같은 미디어 버튼, 볼륨 버튼 모두 지원)
- 기록마다 초 단위 시각 저장
- 진동 확인: 1번 = 짧게 1번, 2번 = 짧게 2번, 취소 = 길게 1번
- 버튼을 1초 이상 누르면 마지막 기록 취소
- 어종 이름은 출조 중이든 끝난 뒤든 언제든 붙이기
- 지난 출조 목록, 카톡 등으로 텍스트 공유

## 설치
Releases 의 `latest` 에서 `fishing-log.apk` 를 받아 설치.
항상 같은 서명키로 빌드되므로 새 버전을 덮어 설치해도 기록이 유지됨.

## v0.4
- 출조 시작 때 배·항구 입력 (목록 저장)
- 지난 출조 · 내 기록 보관함 화면 (어종별 보기, 서버 백업·복원)
- 출조 기록 화면: 합계, 지도, 머문 곳, 물때 그래프, 시간대별 입질, 사진, 전체 기록
- 사진 추가 → 촬영 시각으로 조과 자동 매칭, 그룹엔 작은 사진 공유
- 물때: Open-Meteo 조위 + 달 나이로 물때 단계
- 앱 안에서 새 버전 확인 → 업데이트
- 주꾸미 앱 아이콘

## v0.5
- 지도: 겹친 조과는 크게 묶고 마릿수 숫자, 누르면 상세
- 지도: 출조 중엔 실시간 배 모양 내 위치 (뱃머리 = 진행 방향), 따라가기, 속도·방향
- 지도: 지난 기록 겹치기 (내 기록 + 같은 그룹 친구 기록, 반투명)
- 출조 중 알림: 지워도 다시 뜸, 작은 +1 버튼 두 개
- 사진: 기본 사진 선택 화면으로 최대 30장, 진행 표시
- 배터리: GPS 간격 자동 조절, 절약 모드, 무음 재생은 리모컨 등록 시만, 저장 가볍게, 10시간 출조 알림

## v0.6
- 물때: 국립해양조사원 조석예보(고·저조), 가장 가까운 조위관측소, 폰에 저장(바다에서도 보기), 실패 시 Open-Meteo
- 그룹 화면: 그룹 이름·초대 코드(복사·카톡), 멤버 목록, 출조 달력(출조한 날 강조), 날짜별 출조 카드
- 그룹에서 내 출조 내리기, 0마리 출조는 자동 업로드 안 함
- 공유 사진 1080px, 누르면 큰 사진 + 확대
