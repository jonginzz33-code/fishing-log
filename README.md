# 조과기록 (fishing-log)

블루투스 리모컨 버튼 2개로 낚시 조과를 기록하는 안드로이드 앱.

## 1단계 기능
- 출조 시작/종료
- 리모컨 버튼 등록 (1번, 2번)
- 화면이 꺼져 있어도 리모컨으로 카운트 (재생/다음 곡 같은 미디어 버튼, 볼륨 버튼 모두 지원)
- 기록마다 초 단위 시각 저장
- 진동 확인: 1번 = 짧게 1번, 2번 = 짧게 2번, 취소 = 길게 1번
- 버튼을 1초 이상 누르면 마지막 기록 취소
- 어종 이름은 출조 중이든 끝난 뒤든 언제든 붙이기
- 지난 출조 목록, 카톡 등으로 텍스트 공유

## 설치
Releases 의 `latest` 에서 `fishing-log.apk` 를 받아 설치.
항상 같은 서명키로 빌드되므로 새 버전을 덮어 설치해도 기록이 유지됨.
